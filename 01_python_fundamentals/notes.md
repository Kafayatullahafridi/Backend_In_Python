## Variables

Variables are labels.

They point to objects.

Objects have:

- Identity
- Type
- Value

Useful functions:

- id()
- type()

---

## Mutable Objects

- list
- dict
- set

Mutable means the object itself can change.

---

## Immutable Objects

- int
- float
- bool
- str
- tuple
- complex

Immutable means a new object is created instead of modifying the old one.

---

## Memory Model

Python uses:

- Reference Counting
- Garbage Collection

del removes a reference, not necessarily the object.
